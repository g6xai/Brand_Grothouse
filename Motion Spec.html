Brand System · Motion Spec
Motion Spec · Grothouse · v1.0

Motion as atmosphere. Never theatrics.

The Grothouse family moves slowly on purpose. Aurora meshes drift. Orbs breathe. UI chrome responds crisply but quietly. The archetype a design inherits decides the speed of that atmosphere — a holding company breathes; an AI product snaps. The grammar is the same.

01Motion Principles

Four rules for every motion the family ships.

01 · Motion runs on cellos, not snares

The default rhythm of the family is slow, continuous, breathing. Fast hits and sharp bounces belong to the AI/Tech archetype alone. All other motion is legato — easing in and out, never snapping into place.

02 · Radiance drifts, it does not march

The aurora mesh and orbs move on independent, prime-ratio durations (7s, 9s, 11s, 13s) so they never sync into a visible beat. If you can predict the motion after watching for ten seconds, it's wrong.

03 · UI chrome is snappier than the background

Hovers, focus rings, and button states resolve in 150ms. The background radiance takes 7–13 seconds to cycle. This contrast — crisp foreground, slow background — is the family's motion signature.

04 · prefers-reduced-motion is a full stop

When the user has reduced motion enabled, every orb, aurora, drift, and parallax stops. Cards, transitions, and color changes still work, but all ambient animation freezes. This is non-negotiable.

Orb drift anatomy

Each orb moves through a prime-ratio pair of durations so the two never sync. The standard pair is 9s (primary orb) and 11s (secondary orb) — they resync only every 99 seconds. Intensification reduces the pair to 7s/9s (resync every 63s); subtle extends to 13s/16s (208s).

.orb-a { animation: drift-a 9s linear infinite; }
.orb-b { animation: drift-b 11s linear infinite; }

@keyframes drift-a {
  0%, 100% { transform: translate(0, 0)       scale(1.00); }
  50%      { transform: translate(40px, 30px) scale(1.08); }
}
@keyframes drift-b {
  0%, 100% { transform: translate(0, 0)        scale(1.00); }
  50%      { transform: translate(-30px, -20px) scale(1.06); }
}

06Staggering & Sequencing

When multiple things move, they do not all move at once.

  • Hero reveal — eyebrow (0ms) → headline (60ms) → accent phrase (160ms) → lead (260ms) → CTA (380ms). Each on 450ms emphasized.
  • Card grid reveal — cards enter with 40ms stagger. Max stagger capped at 280ms so the last card doesn't feel abandoned.
  • Navigation — nav items never stagger on load. They appear instantly with the page. Only content staggers.
  • Numeric reveal — stat labels fade in (300ms), then numbers count up (1400ms emphasized). The count is the event, not the appearance.
  • Form field focus — label color, border color, and focus ring all animate simultaneously at 120ms. No staggering within a single input.
/* Hero stagger example */
.hero .eyebrow { animation: reveal 450ms var(--g-e-emph)    0ms both; }
.hero h1       { animation: reveal 450ms var(--g-e-emph)   60ms both; }
.hero .accent  { animation: reveal 450ms var(--g-e-emph)  160ms both; }
.hero .lead    { animation: reveal 450ms var(--g-e-emph)  260ms both; }
.hero .cta     { animation: reveal 450ms var(--g-e-emph)  380ms both; }

@keyframes reveal {
  from { opacity: 0; transform: translateY(12px); }
  to   { opacity: 1; transform: translateY(0);    }
}
07Accessibility

prefers-reduced-motion is a full stop.

When the user has reduced motion enabled, all orb drift, aurora mesh, parallax, count-up animations, and decorative ambient motion stops. UI chrome transitions (hover, focus, modal) can continue at reduced duration (80ms) or disable entirely — both are acceptable.

@media (prefers-reduced-motion: reduce) {
  *, *::before, *::after {
    animation-duration: 0.01ms !important;
    animation-iteration-count: 1 !important;
    transition-duration: 0.01ms !important;
  }
  .orb, .aurora, .noise { animation: none !important; }
  .counter-up           { animation: none !important; }
}

This snippet lives at the bottom of kit/grothouse-system.css. Never override it in an application stylesheet.

08Do & Don't

The motion temperament.

✓ Do
  • Let orbs breathe on prime-ratio durations (7/9/11/13s).
  • Match the archetype's speed multiplier for every UI transition.
  • Stagger hero reveals at 60–80ms intervals, capped at 380ms total.
  • Count up large stats over 1400ms, emphasized easing.
  • Respect prefers-reduced-motion without exception.
✕ Don't
  • Bounce. No overshoot easing, no spring physics, no elastic.
  • Animate the serif display letters individually — the wordmark never wobbles.
  • Use parallax scrolling. The family's surfaces are flat by design.
  • Stagger more than 6 elements — it reads as gimmick, not reveal.
  • Use ease-in-out shorthand. Always specify the named cubic-bezier.
