Grothouse Design System

Typography

One family. Five sizes. Sentence case. Everything else that used to be here — a serif display face, a separate body sans, and a wide-tracked uppercase mono overline — is retired.

The family

--font-system

-apple-system, BlinkMacSystemFont, SF Pro Text, SF Pro Display, Segoe UI, system-ui, sans-serif

The system stack renders as San Francisco on Apple platforms and Segoe UI on Windows. It ships with the operating system, so there is no webfont to download, no flash of unstyled text, and no licence to track.

The floor is 12px

The original standard specified a 13px floor. A runtime audit found 445 elements at 12px, every one of them conformant to Apple and a violation only against our own stricter number. Enforcing 13px would have meant editing 445 call sites away from what Apple ships.

The rule was deleted rather than loosened. 13px remains the default caption size; 12px is a deliberate step down for fine print, not an alternative to it. Below 12px is still banned.

Re-measurement reversed a rule. That is the mechanism working, and it is why no number here should be defended without measuring again.

Sentence case, always

Measured on apple.com — home and iPhone pages, mobile and desktop:

MetricResult
text-transform: uppercase 0 elements
letter-spacing above 0.1em 0 elements

Zero, on all four page and viewport combinations. Sentence case is not a preference here — it is the observed rule. Retiring the industrial overline therefore means removing the uppercase transform and the wide tracking, not only the font family.

Weight

Apple leans on 600 far more than 400. Measured by frequency on the apple.com home page at mobile width, 17px / 600 is the single most common pairing at 147 occurrences — ahead of 17px / 400 at 51.

Treat semibold as the default for labels, links and card titles. Regular is for running prose.

The one surviving monospace

Machine identifiers where character alignment carries meaning: NMLS numbers, loan IDs, hash digests, API key prefixes.

NMLS 1234567 · Loan XM-2026-0041

.font-id · system mono · 13px · tabular-nums

It is not a decorative treatment. Mono on a label, a button or an overline is the retired industrial style wearing a new name.

Containment

Text never escapes its box. This is a hard gate, not a review opinion.

UtilityDoesRule
.hig-truncate Single line, ellipsis Must carry a title attribute with the full value
.hig-wrap-safe Multi-line, breaks anywhere For emails, IDs and URLs in flex or grid children
.hig-prose Caps measure at 65ch Every block of running text

No fixed height on any element containing text. Use padding and let content size the box. A fixed height is what clips text at 200% zoom, and flex and grid children default to min-width auto — every one containing text needs min-w-0, which is the single most common cause of drift.
