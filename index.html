Grothouse Design System v2.0.0

The Grothouse Family Brand System

Apple Human Interface Guidelines. Black, white, grey, and one accent per surface. This repository is the foundation that sites, products and collateral build on — it is not any of those things itself.

The canonical standard is DriveX/design/APPLE-HIG-STANDARD.md. It is measured against apple.com rather than asserted, and it is not copied here — a duplicated standard across fifteen repos guarantees divergence. This repo records only its own deltas, in docs/APPLE-HIG-STANDARD.md.

Where a local document and the canonical standard disagree, the standard wins and the local document is the bug.

The colour law

Two accents. One per surface, always consumed as --color-primary. A hex literal in a component is a violation.

Source of truth

Enforcement

A standard enforced by review does not survive a deadline. The gate runs in CI on every pull request.

The ratchet

scripts/hig-lint-ratchet.mjs counts violations per section and fails if any category grew. The baseline only moves down.

Measured measurement

Every rule carries known-bad and known-good fixtures. A probe never checked against a known-good input is not evidence.

Token parity

scripts/build-tokens.mjs --check fails if the CSS layer or the JS mirror drifts from tokens.json.
