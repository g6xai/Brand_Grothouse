04 How to Build on This

For a new site or product

  1. Pick an entity from kit/tokens.json.
  2. Set its attributes on <html>.
  3. Import kit/grothouse-system.css.
  4. Load the three Google Fonts.
  5. Compose using only --g-* semantic tokens.
  6. Reference the three spec documents when making decisions.

Root template

<html data-entity="grothouse_family"
      data-archetype="holding"
      data-surface="cool"
      data-glow="medium"
      data-preset="editorial"
      data-theme="light">
  <link rel="stylesheet"
        href="kit/grothouse-system.css">
</html>

Light is the default — always set the theme attribute explicitly.

05 What Comes Next

Build on this foundation

This package is the constitution, not the country. With these three documents and the kit, any team can produce:

  • Marketing websites for any of the 24 entities
  • Product UI for internal tools and customer apps
  • Printed collateral — letterhead, business cards, annual reports
  • Pitch decks and investor communications
  • Signage, wayfinding, and environmental graphics
  • Social and ad creative

Spec sheets, handed to design

When a new artifact is needed, the commissioning brief should cite:

  • The entity (or confirm it's family-level)
  • The archetype (drives motion + radii)
  • The preset (editorial / brutalist / glass / minimal / maximalist)
  • The surface tone and glow level

All four are enumerated in kit/tokens.json.
